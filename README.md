# IWC Woodland — концепт-лендинг

Концепт-редизайн для портфолио (FR — основной язык, переключатель FR / DE / RU, ссылка `?lang=de`): покадровый **scroll-scrub** на `<canvas>`. Ролик IWC о том, как Pilot's Watch Chronograph TOP GUN «Woodland» собирается из пигмента, керамики, механизма и нитей, проигрывается фоном на весь экран по мере прокрутки, поверх идут семь коротких глав. Не официальный сайт IWC Schaffhausen.

## Запуск локально

```bash
python3 -m http.server 8778
# затем открыть http://localhost:8778
```

## Как устроено

- `index.html` — весь сайт (инлайн CSS/JS)
- `frames/` — 431 кадр (`f_0001.jpg` … `f_0431.jpg`), 12 к/с, 640×800, ~14 МБ; на телефоне грузится каждый 2-й кадр (~7 МБ)
- `video/source.mp4` — исходный ролик (на сайт не выкладывается)

Скролл по точкам: один жест колеса, свайп или клавиша — одна глава; видео само доигрывает до следующей точки (`STOPS`) с плавным разгоном и торможением, лишний ввод во время перехода игнорируется (включая инерцию трекпада). Со сцены вниз — только после последней главы; при возврате снизу сцена ловит на последней главе. Между кадрами — кроссфейд.

Раскладка кадра зависит от экрана: на широком — кадр на всю высоту справа, края растворяются в размытой копии; на портретном — кадр целиком по ширине сверху, текст снизу.

Главы привязаны к прогрессу через `data-seg="a,b,c,d"` (вход → видно → уход) у каждого `.cap`; соседние главы не пересекаются.

## Деплой

Статический сайт, Vercel без сборки: `vercel deploy --prod`.
