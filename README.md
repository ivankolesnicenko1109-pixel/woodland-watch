# Woodland — концепт-лендинг

Кинематографичный лендинг с покадровым **scroll-scrub**: ролик о том, как пилотский хронограф собирается из пигмента, керамики, механизма и нитей, нарезан на 575 кадров (16 к/с) и проигрывается на `<canvas>` по мере прокрутки. Рядом — семь глав с типографикой (Cormorant Garamond + Manrope + JetBrains Mono), строки раскрываются из-под маски синхронно со скроллом. Прогресс показывает маленький циферблат-хронограф.

## Запуск локально

Кадры грузятся по HTTP, поэтому нужен статический сервер:

```bash
python3 -m http.server 8778
# затем открыть http://localhost:8778
```

## Структура

- `index.html` — весь сайт (инлайн CSS/JS)
- `frames/` — 575 кадров (`f_0001.jpg` … `f_0575.jpg`), шаг 0.0625 с, 640×800; финальная заставка с логотипом отрезана
- `video/source.mp4` — исходный ролик

Главы привязаны к прогрессу через `data-seg="a,b,c,d"` (вход → видно → уход) у каждого `.cap`.

## Деплой

Статический сайт — деплоится как есть на Vercel / Netlify / GitHub Pages, без сборки.
